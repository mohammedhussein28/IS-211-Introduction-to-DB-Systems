# ⚡ Energy Grid App
### Renewable Energy Management System

A database-driven web application developed using **Flask, Python, and Microsoft SQL Server** to manage renewable energy infrastructure, monitor power unit performance, track maintenance activities, and generate operational reports.

Developed as part of **IS211 – Introduction to Database Systems** at the Faculty of Computers and Artificial Intelligence.

## 🚀 Features

### 📊 Dashboard
- Overview of renewable energy infrastructure and system statistics.
- Centralized access to power units, technicians, inspections, and maintenance information.

### ⚡ Power Unit Management
- Manage renewable energy power units.
- Monitor unit efficiency and operational status.
- Automatically calculate unit status based on efficiency readings.

### 👷 Technician Management
- Manage technician information.
- Organize maintenance and inspection personnel records.

### 🔍 Inspection Tracking
- Record and track power unit inspections.
- Monitor efficiency readings and inspection results.
- Automatically update unit status based on efficiency measurements.

### 🔧 Maintenance & Replacements
- Track replacement records and spare parts.
- Monitor maintenance alerts.
- Maintain records of equipment maintenance activities.

### 📈 Reports & Analytics
- Visualize operational data using interactive **Chart.js** charts.
- Generate inspection reports.
- Export inspection data to **CSV** for further analysis.

## 🏗️ System Overview

The application connects a Flask-based web interface to a Microsoft SQL Server database.

**Frontend (HTML, CSS, JavaScript)**  
↓  
**Flask Application (Python)**  
↓  
**Microsoft SQL Server Database**

Users interact with the web interface to manage renewable energy resources, while Flask handles application logic and database operations.
